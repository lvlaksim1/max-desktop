1. Выпущена v0.1.20: https://github.com/lvlaksim1/max-desktop/releases/tag/v0.1.20; сборки/автоматические проверки GitHub Actions 40399496951 и release 40399495892 success, Setup/Update/SHA256 доступны.

3. Зафиксировать итог: серверный отказ, отсутствие ID бота, открытие настоящего miniapp, отказ в доверенном устройстве или проблема MAX Bridge. Для анализа достаточно категории и обезличенного скриншота; подписанный URL с секретами не копировать.
4. Признать поддержку полноценного запуска принятой только после реального испытания. Обычная отправка сообщений отключена, VPN не менять, QR/TinyFish не применять.
