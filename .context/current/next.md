# MAX Desktop — следующий практический шаг, 27.10.2026
1. Владелец может запустить подготовленный командный файл `scripts/android-usb-preflight.cmd` на подключённом Android. Достаточно уже имеющегося adb; PowerShell не требуется. Проверить синтетический round-trip, сведения о MAX и показания mobile_data/wifi_on/gsm.network.type. `PASS` подтверждает лишь USB-обмен.
2. По результату выбрать следующий доказательный участок: пассивное наблюдение штатного MAX без нарушения существующей доверенной привязки, с анализом мобильного вызова по изученному APK 26.35.1 в качестве рабочей гипотезы для 26.36.2.
3. Проводить испытания только с собственным аккаунтом/тестовой SIM, не извлекать или публиковать коды, подписанные ссылки, сеансы и операторские подтверждения; не обходить защиту скриншотов.
4. Сохранять план docs/plans/android-mobileid-desktop-integration-2026-10-27.md; не выпускать новую Windows версию до успешной проверки конечной функции.
