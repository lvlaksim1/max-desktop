# MAX Desktop — следующий этап мобильной совместимости

1. Проверить GitHub Windows CI и выпуск v0.1.21 (диагностика), наличие Setup/Update/SHA256. Код диагностики прошёл CI 40401896435.
2. После обновления посмотреть у активного аккаунта строку «Протокол: ...», затем открыть кнопку «Посмотреть код» и посмотреть «Платформа запуска в URL: ...». Эти строки не содержат действительных кодов или URL и пригодны для технической диагностики.
3. Сопоставить значения, не предполагая, что WEB, Android UA и WebAppPlatform взаимозаменяемы. Для мобильной совместимости развивать легитимный мобильный клиент, а проверку доверенного устройства проходить предусмотренным MAX способом.
4. Не переписывать WebAppData, не фальсифицировать идентификатор доверенного устройства и не перенаправлять пользовательский код/подписанные адреса в журнал. Системный VPN оставить неизменным, отправка обычных сообщений отключена.
