# MAX Desktop — следующая пользовательская проверка
1. Установить https://github.com/lvlaksim1/max-desktop/releases/download/v0.1.23/MaxDesktop_Update_v0.1.23.exe ; релиз проверен Windows CI и опубликован.
2. Открыть тот же бот «Коды подтверждения» и нажать «Посмотреть код». Вверху сверить текущий номер аккаунта, затем строку: а) мост не подключён; б) мост активен, но Mobile ID request не получен; в) запрос получен, ответ не доставлен; г) no_cellular доставлен.
3. Если ошибку no_cellular доставили, а форма SMS не появилась, исследовать разрешённые сервером условия 2FA и конкретного типа кода; не вставлять номер аккаунта в неподдерживаемое поле запросов.
4. Действующие авторизации и VPN не менять, секретные URL, SMS и коды не логировать и не запрашивать у пользователя.
