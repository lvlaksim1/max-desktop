# MAX Desktop — первые действия следующего чата

1. Восстановить `project-manager` по `.context/ENTRYPOINT.md`, проверить marker поколения и все 8 Git SHA капсулы.
2. Последний выпуск **v0.1.11**: https://github.com/lvlaksim1/max-desktop/releases/tag/v0.1.11 . Windows CI 40330935479 и release 40331289185 успешны. Старые выпуски удалены.
3. Системный VPN **не отключать и не изменять**. На ПК владельца через физический IPv4 установлен SESSION_INIT, транспортную ошибку TLS не переисследовать без новых данных.
4. В v0.1.10 VK Captcha появлялась, пользователь установил зелёную галочку, но окно не закрывалось; самодельный iframe обработчик не использовал SDK SUCCESS. v0.1.11 использует локально встроенный @vkid/captcha@2.0.0 и SUCCESS({token}) → одно solved сообщение WebView2. Автономный тест есть; пользовательская приёмка ожидается.
5. Следующее действие — проверить установленную v0.1.11: одна попытка запроса кода, ручная проверка VK, затем при успехе SMS→код→2FA если потребуется→LOGIN→восстановление сеанса.
6. При повторном зависании запросить **только** обезличенную диагностику и снимок без номера, кода, URL капчи и токенов. Никаких автоматических обходов проверки человека.
7. Локальные тесты — только приватный `lvlaksim1/pc-runner-gateway` с точным SHA, GitHub Actions для Windows сборок; без TinyFish. Далее чаты, отправка сообщений, GUI/трей.
