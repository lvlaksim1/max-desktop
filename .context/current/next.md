# Следующие действия

1. Пользователь закрывает MAX Desktop v0.1.1 и вручную запускает `MaxDesktop_Update_v0.1.2.exe` с последнего GitHub Release.
2. После установки подтверждает v0.1.2 в заголовке и сохранение настроек/темы/разделителей.
3. При любом повторении `ProtocolException` собрать безопасные сведения: где показана ошибка, после какого действия, время и номер версии; не пересылать SMS-коды, пароли, токены.
4. Проверить обновление по кнопке уже после перехода на v0.1.2 (при появлении следующего выпуска).
5. Затем продолжить приёмку реальной авторизации MAX, способов подтверждения и последующего получения чатов.
