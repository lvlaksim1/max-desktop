# MAX Desktop — следующий этап 27.10.2026

1. Принять результаты теста: мобильный сеанс TCP/Android и WebAppPlatform=android подтверждены владельцем. Переход в miniapp проходит, но сервис кодов требует отдельной штатной привязки доверенного устройства.
2. Для получения защищённых кодов использовать официальное мобильное устройство со своей SIM, Mobile ID или поддерживаемое официальное СМС-подтверждение. Не выдавать компьютер за привязанное устройство путём смены User-Agent/DeviceId/WebAppData.
3. Если владельцу требуется ускорить загрузку, сначала собрать локальную обезличенную длительность WebView2 initialization/navigation и DOM-ready; страница уже загружается, причина 1–2-минутного ожидания неизвестна. Не регистрировать адрес подписанного запуска и содержимое кодов.
4. Для общей функциональности продолжить проектирование отдельных сохранённых WEB и TCP сеансов с резервным копированием (docs/protocol/mobile-session-isolation-plan-2026-10-27.md). Последняя версия остаётся v0.1.21.
