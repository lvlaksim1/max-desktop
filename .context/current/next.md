# Следующие действия

1. Пользователь устанавливает v0.1.7 из GitHub Release.
2. В окне «Добавить аккаунт» выбирает **«WebSocket (веб-протокол)»** и нажимает «Проверить соединение (без номера)». Сообщает только скопированный обезличенный текст.
3. Если INIT подтверждён, делает один SMS-запрос. При реакции сервера уточнить поддержку кода, капчи и 2FA; продолжить до принятого LOGIN.
4. Проверить X→трей, «−»→панель задач, правую кнопку на значке трея→«Выход», повторный запуск→одно окно; также сохранение настроек при обновлении.
5. После серверной авторизации — чаты, сообщения и уведомления.
