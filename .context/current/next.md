# Следующие действия

1. Провести приёмку Setup 0.1.0 на Windows (окна, значок в области уведомлений, темы, размеры и состояние окон, удаление).
2. Исправить замечания без изменения неподтверждённой сетевой логики; повторить Windows CI.
3. Получить подтверждённый динамический протокол MAX для собственного тестового аккаунта.
4. Реализовать сначала авторизацию, затем получение чатов, сообщений и отправку.
5. Выпустить и проверить обновление поверх v0.1.0 после следующей версии.
