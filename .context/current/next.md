# MAX Desktop — первые действия следующего чата

1. Восстановить того же project-manager по .context/ENTRYPOINT.md и проверить state-integrity.json.
2. Выпуск v0.1.9 опубликован. Системный VPN владельца нельзя изменять или отключать. Трафик MAX разрешено вести через выбранный приложением физический IPv4.
3. На ПК владельца Gateway #399/#400 доказал HTTPS и WS 101 при работающем VPN, #402 подтвердил выбор подходящего сетевого интерфейса. На GitHub Windows 40322276206 новый C# модуль подтвердил SESSION_INIT; 40323017999 опубликовал два установщика v0.1.9 с контрольной суммой.
4. Следующее: обновить установленный MAX Desktop до v0.1.9, «Добавить аккаунт» → «Автоматически» → «Проверить соединение (без номера)». При подтверждении INIT выполнить один запрос SMS, код/2FA/LOGIN.
5. Не предлагать выключить VPN. Локальные задания отправлять через приватный pc-runner-gateway с точным SHA и .pc-gateway/tasks; без TinyFish и секретов.
6. Затем завершить чаты и пользовательскую GUI-приёмку.
