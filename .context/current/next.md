# Следующие действия

1. Обновиться до v0.1.6 поверх установленной версии.
2. Открыть `Добавить аккаунт → Проверить соединение (без номера)`. Получить сообщение о системном прокси, ходе подключения и результате `SESSION_INIT`. Сообщение копируется кнопкой «Копировать» без номера и секретов.
3. При успешном подключении отдельно попробовать запрос кода.
4. Если системного прокси нет и все три узла снова показывают TLS EOF, проверить тот же тест через другую сеть, в частности мобильную точку доступа, чтобы отделить сетевое ограничение от ошибки кода клиента.
5. Продолжить протокол авторизации после подтверждения сетевой доступности.
