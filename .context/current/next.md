# MAX Desktop — следующее действие после согласования плана 27.10.2026
1. Начать этап 1: восстановить по оригинальному APK Android 26.35.1 цепочку запуска WebAppVerifyMobileId → TRANSPORT_CELLULAR → HTTP → ответ в mini-app → серверное решение. Отметить непроверенные места.
2. Подготовить этап 2: подтвердить операторскую проверку и привязку в оригинальном MAX на физическом Android с тестовой SIM и мобильными данными, без сбора кодов/токенов.
3. После эталона: этап 3 USB Windows/Android на синтетических данных; этап 4 серверная совместимость (или доказанный отказ); параллельно этап 5 настоящая SMS-ветка при включённой 2FA.
4. Только затем этап 6: интеграция подтверждённой схемы и новый выпуск после показа настоящего кода в окне Windows.
Согласованная спецификация: docs/plans/android-mobileid-desktop-integration-2026-10-27.md. Действующие сеансы и VPN не менять.
