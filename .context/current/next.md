# MAX Desktop — что проверить после v0.1.22

1. Убедиться, что сборка v0.1.22 прошла полноценный Windows CI и опубликован выпуск. Проверить соответствующие ссылки, не выдумывать время/файл.
2. Тестовая учётная запись: 2FA должен быть включён через мобильное приложение MAX; открыть «Коды подтверждения» → последнее сообщение от Госуслуг → «Посмотреть код» → «Привязать новое устройство». Проверить, появляется ли серверный ввод СМС после no_cellular.
3. Если нет, рассмотреть признаки того, что JS bridge не активирован или ошибка не доставляется, без доступа к токенам или содержимому кода. Не создавать фиктивный SMS challenge.
4. Подробности: docs/protocol/sms-fallback-mobileid-2026-10-27.md. Системный VPN и активные Windows аккаунты не менять.
