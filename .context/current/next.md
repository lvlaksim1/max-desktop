# Следующие действия

1. Обновить установленный MAX Desktop до v0.1.4 через кнопку либо `MaxDesktop_Update_v0.1.4.exe` с GitHub Release.
2. Открыть `Добавить аккаунт → Проверить соединение (без номера)`; проверить статус. Никаких учётных данных в диагностике не передаётся.
3. При успехе `SESSION_INIT` запросить код в отдельной попытке; при ошибке передать только обезличенный текст и этап.
4. При `TLS_HANDSHAKE EOF` после 1–3 попыток исследовать сеть пользователя, а не повторять без доказательств одни и те же настройки TLS.
5. При подтверждённой авторизации продолжить функциональность чатов и сообщений.
