# MAX Desktop — следующее действие после аудита SIM/Mobile ID

1. Отчёт по оригинальному MAX APK: docs/protocol/verified-apk-sim-mobileid-audit-2026-10-27.md, https://github.com/lvlaksim1/max-android-research/blob/main/docs/telephony-api-audit-26.35.1.md.
2. Номер аккаунта уже есть в MaxSavedSession.Phone; в исходном APK отсутствуют найденные штатные вызовы чтения номера SIM. Защищённая проверка связана с Mobile ID и привязкой доверенного устройства; сохранять корректный Android TCP-сеанс, не подделывать Mobile ID.
3. Разобраться, предоставляет ли MAX документированную поддержку доверенного настольного устройства для защищённых кодов или законную альтернативу; если нет, объяснить эту функциональную границу. Не обещать, что User-Agent/номер аккаунта её обойдут.
4. Пользовательские установщики не менять до наличия реального, проверенного функционального исправления. Системный VPN не менять, QR/TinyFish/отправку обычных сообщений не включать.
