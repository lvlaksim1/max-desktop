# MAX Desktop — дальнейшие шаги после Mobile ID исследования

1. Технический отчёт: docs/protocol/mobile-id-native-verification-deep-research-2026-10-27.md; полная трассировка: https://github.com/lvlaksim1/max-android-research/blob/main/docs/mobileid-bridge-trace-26.35.1.md .
2. Установлено: Android через приватный WebAppVerifyMobileId выбирает сотовую сеть и возвращает HTTP-результат; номер телефона не аргумент операции. Запись аккаунтного номера в «SIM» не является операторской привязкой.
3. Для доступа к защищённым кодам именно на ПК проверить официальный допустимый путь регистрации доверенного настольного устройства; пока не подтверждён. Штатный Mobile ID на телефоне с SIM — отдельный сценарий.
4. Для диагностики задержки 1–2 мин только обезличенные тайминги, без мобильных URL/headers/body, секретов и кодов.
5. VPN неизменен. Нового установщика после v0.1.21 нет.
