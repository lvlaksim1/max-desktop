# Следующие действия

1. Проверить на Windows версию v0.1.1, особенно читаемость светлых выпадающих списков в тёмной теме.
2. Испытать «Добавить аккаунт» и сообщить, принял ли MAX запрос подтверждения; не передавать код, токен или пароль через чат.
3. При вводе правильного кода проверить реальный статус LOGIN; если прошло — перезапуск и восстановление сеанса.
4. Если сервер требует звонок или другой способ, развить соответствующую ветвь по подтверждённым ответам.
5. Затем подключить список чатов и историю сообщений; расширить хранилище под несколько аккаунтов.
