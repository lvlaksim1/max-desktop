# Следующие действия

1. Установить v0.1.5 поверх предыдущей версии через кнопку обновления либо Update-инсталлятор.
2. Выполнить `Добавить аккаунт → Проверить соединение (без номера)`. При успехе показывается выбранный рабочий узел и `SESSION_INIT`; при сбое — этап, имена трёх серверов и обезличенные категории ошибок.
3. Если соединение успешно, отдельно запросить код, чтобы проверить фактический AUTH_REQUEST.
4. Если для всех серверов TLS_HANDSHAKE/EOF до сертификата повторяется, исследовать доступность из альтернативной сети и конфигурацию маршрутизации/прокси вместо новых необоснованных предположений.
5. Только после успешного входа переходить к реализации чатов и переписки.
