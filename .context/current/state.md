# MAX Desktop — состояние 27.10.2026: сотовый INTERNET на Android реально проверен
- Оригинальный MAX 26.36.2 на физическом Android 15 с подходящей SIM прежде уже показывал настоящие коды; последний просмотр произошёл сразу без новой привязки, поэтому новое Mobile ID событие не подтверждено.
- USB ADB ранее проверен синтетической строкой: PASS. **Новое выполненное испытание через PC Gateway:** Android `dumpsys connectivity` показал 3 записи NetworkAgentInfo, из них 3 CELLULAR, 2 CELLULAR+INTERNET и 2 CELLULAR+INTERNET+VALIDATED. Действительный запрос [#491](https://github.com/lvlaksim1/pc-runner-gateway/issues/491) завершился SUCCESS; `#489` — первый удачный разбор без подробного статуса. Подробности: docs/protocol/android-cellular-connectivity-verified-2026-10-27.md.
- По APK оригинальный запрос мобильной сети требует `TRANSPORT_CELLULAR` и `NET_CAPABILITY_INTERNET`; требуемые системные возможности на телефоне наблюдаются. Это **не** доказательство того, что Mobile ID фактически выполнен, сервер признал настольную операцию или код доступен на Windows.
- Источник прежней схемы: max-android-research/docs/mobileid-bridge-trace-26.35.1.md. Рабочее предположение по указанию владельца: релевантный механизм одинаков в MAX 26.35.1/26.36.2.
- Windows MAX Desktop v0.1.23 не показывает защищённые коды. Ни приложение, ни аккаунты, ни системный VPN тестом не менялись.
