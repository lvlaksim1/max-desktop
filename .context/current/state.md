- **Последний выпуск — v0.1.10**, Setup/Update/SHA-256, в GitHub оставлен только текущий релиз: https://github.com/lvlaksim1/max-desktop/releases/tag/v0.1.10. Проверки WPF/протокола/механизма обновления — success в Actions 40325552079; выпуск — success 40325831275.
- **Подтверждено владельцем на установленной v0.1.9:** при включённом и неизменном VPN режим «Автоматически (сначала физический интерфейс)» успешно подтвердил защищённое WebSocket-соединение и SESSION_INIT. Прежний TLS-сбой разрешён на уровне приложения.
- **Оставшийся отказ:** на запрос «Получить код» сервер ответил `WS_AUTH_REQUEST: Проверка не пройдена, попробуйте ещё раз`. Это стадия AUTH_REQUEST(17), не TLS.
- **Вероятная причина:** требование проверки человека VK ID. Публичное исследование Web MAX описывает CAPTCHA_REQUEST(224), ссылку проверки и captchaToken в START_AUTH(17). Достоверный внутренний код отказа пользователя пока неизвестен.
- **v0.1.10:** ручное предъявление капчи в изолированном WebView2, при решении передача captchaToken серверу; автоматические повторные SMS запрещены. ПК-вызов gateway #403 подтвердил доступность id.vk.ru с работающим VPN (HTTP 302). Офлайн проверки новой логики успешны.
- **Не подтверждены:** реальное отображение и решение капчи в установленной v0.1.10, получение кода, 2FA, LOGIN, рабочие чаты/сообщения и полная GUI-приёмка.
