# MAX Desktop — состояние 27.10.2026: план Android + SIM согласован
- Текущий проверенный выпуск продукта v0.1.23. Пользовательская приёмка функции кодов отрицательная: остаётся «Проверяем номер телефона», настоящий код в окне Windows не получен; отметка о MAX Bridge генерировалась собственным скриптом и не доказывала вызов WebAppVerifyMobileId.
- По оригинальному APK MAX 26.35.1 статически установлено: WebAppVerifyMobileId(requestId,url), сотовый HTTP-запрос и передача ответа мини-приложению. Неизвестно, по каким правилам сервер доверяет конкретному устройству/сеансу.
- Владелец согласовал шесть этапов разработки с реальным Android и исследовательской SIM: исходники, эталонное испытание, USB-канал, серверная совместимость, SMS с 2FA, интеграция/приёмка. План сохранён: docs/plans/android-mobileid-desktop-integration-2026-10-27.md.
- Это только запись плана. Работающие аккаунты, маршрутизация, VPN и установщики не изменялись.
