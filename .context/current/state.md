# MAX Desktop — состояние 26.10.2026

- Публичный `lvlaksim1/max-desktop`, `main`, один постоянный `project-manager`; частный удалённый исполнитель `lvlaksim1/pc-runner-gateway`.
- **Последний выпуск — v0.1.12** https://github.com/lvlaksim1/max-desktop/releases/tag/v0.1.12 . Опубликованы Setup/Update/SHA256, оставлен только последний релиз. CI 40340814912, release 40341203011 — success.
- **Реальная пользовательская приёмка:** при неизменном включённом VPN новый физический WebSocket-канал подтвердил INIT; VK Captcha в v0.1.11 проходит, SMS доставляется. После ввода кода окно не продвинулось, осталось сообщение «Запрос принят». Второй скрин показал отказ анонимной проверки: «Нельзя проверить соединение во время активной авторизации».
- **Установленная причина:** код VERIFY_CODE/LOGIN возвращал реальную ошибку при сохранённом AwaitingVerification, но LoginWindow.ShowResult перезаписывал её сообщение на текст отправки SMS. Значит, нельзя утверждать, что код был принят: реальный результат скрывался. При закрытии диалога PendingAuth также не очищался, блокируя Probe в следующем окне.
- **Исправление v0.1.12:** показ текста AuthResult.Error в AwaitingVerification; подготовка/очистка незавершённого сеанса при закрытии, без потери Connected; испытания отказа CODE_ENTER(18) и LOGIN(19), последующей проверки анонимного соединения. Автоматических SMS нет.
- **Открытые вопросы:** точная серверная ошибка после кода неизвестна до новой приёмки; настоящий 2FA/LOGIN и состояние чатов не подтверждены. Никаких изменений VPN и использования QR.
- **Следующее действие:** установить v0.1.12, один раз пройти SMS и код; при неуспехе получить обезличенную ошибку WS_CHECK_CODE/WS_LOGIN для следующего адресного исправления.
