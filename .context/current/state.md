# MAX Desktop — состояние 27.10.2026, исследование номера SIM и Mobile ID

- Менеджер project-manager, репозиторий lvlaksim1/max-desktop, main. Последний выпущенный клиент v0.1.21, сеанс владельца TCP(Android) через физический интерфейс. Сервер BOT_WEB_APP(160) возвращает платформу android. Кнопка «Посмотреть код» открывает настоящий мини-сервис, но он требует доверенное устройство с привязкой по оператору/SIM.
- По требованию владельца найден и полностью перепроверен исходный APK MAX 26.35.1 (6867) из Release lvlaksim1/max-android-research: 24 272 Java-файла через JADX. Стандартные методы getLine1Number, SubscriptionManager.getPhoneNumber, getSimSerialNumber, getSubscriberId в исходниках не обнаружены. getNetworkOperator 4; getSimOperator 2. Есть отдельный вызов WebAppVerifyMobileId и модель VerifyMobileIdResponseInfo. Отчёт: https://github.com/lvlaksim1/max-android-research/blob/main/docs/telephony-api-audit-26.35.1.md.
- В клиенте номер аккаунта уже хранится в MaxSavedSession.Phone. Его подстановка в поле SIM/подписанный URL не подтверждает фактическое владение мобильной SIM и не является штатной привязкой Mobile ID. Не реализована подмена защищённой проверки; рабочие сеансы и VPN неизменны.
- Описание исследования: docs/protocol/verified-apk-sim-mobileid-audit-2026-10-27.md. Нового релиза нет.
