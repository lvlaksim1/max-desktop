# MAX Desktop — ограничения после v0.1.15

1. **GET_CHATS реализован, но реальная приёмка открыта.** Есть успешная Windows CI и синтетические тесты формата; подтверждения, что сервер вернул пользовательские переписки, пока нет.
2. **История и отправка сообщений отсутствуют.** UI не должен выдавать заглушки за содержимое реальной переписки.
3. **DPAPI восстановление после перезапуска**, многопрофильность, события, вложения, уведомления и GUI-приёмка пока открыты.
4. **Другой аккаунт:** новый вход ограничен до установки пароля на Android, MAX установил ожидание суток. Успешный другой аккаунт уже есть.
5. **Инварианты:** системный VPN не изменять; без QR/TinyFish; приватные чаты/токены/телефоны не публиковать.
