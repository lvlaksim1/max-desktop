# Непроверенные участки

- **Неизвестно**, позволяет ли сеть пользователя установить TLS с `api.oneme.ru` или `api-tg.oneme.ru`. В v0.1.4 все DNS-адреса основного сервера закрывали TLS до сертификата. Ждём тест v0.1.5.
- Независимое подтверждение TLS в GitHub Windows относится к другой сети и не доказывает доступность из пользовательской сети.
- Реальная серверная авторизация, доставка кода, подтверждение звонком, 2FA, восстановление сеанса, чаты и сообщения пока не подтверждены.
- Нельзя убирать TLS-валидацию и нельзя передавать номер телефона в общедоступный журнал для диагностики.
