# MAX Desktop — блокирующие условия после v0.1.10

1. **Реальная проверка человека ещё не принята.** На v0.1.9 START_AUTH отказан сообщением «Проверка не пройдена, попробуйте ещё раз». Вероятно требуется VK ID CAPTCHA_REQUEST, но точный error code конкретного сеанса не известен.
2. **Окно VK Captcha и передача токена в v0.1.10** прошли компиляцию и автономные тесты, но фактическое отображение проверки, получение токена из страницы и ответ сервера после неё ожидают пользовательской приёмки.
3. **SMS, код, 2FA и LOGIN** не подтверждены реальным аккаунтом. Не считать имитационный вход настоящим.
4. **Чаты, вложения, уведомления, полная GUI-приёмка** остаются открыты.
5. **Инварианты:** VPN включён, его настройки изменять нельзя. QR не использовать. Код, номер, сессионные и CAPTCHA-токены не публиковать; не повторять неопределённый SMS автоматически.
