# MAX Desktop — открытые условия после первого успешного входа (26.10.2026)

1. **Базовая SMS+2FA авторизация теперь подтверждена** на одном аккаунте, где пароль был заранее установлен. Не считать успешный LOGIN глобальным блокером.
2. **Для другого аккаунта действует ограничение MAX по времени:** на уже авторизованном Android пароль для нового устройства можно будет установить лишь спустя сутки по сообщению сервера. Не предлагать обход.
3. **Чаты и сообщения не реализованы.** GetChatsAsync/GetMessagesAsync возвращают пустые списки, отправка не поддерживается; нельзя назвать их работающими.
4. **Восстановление защищённой сессии, несколько аккаунтов, уведомления, вложения и GUI** ещё не приняты. Факт наличия сохранения DPAPI в коде не заменяет проверку перезапуска.
5. **Закрытие окна авторизации исправлено в v0.1.14 и проверено в Windows CI**, но пользовательский снимок успеха ещё с v0.1.13. Требуется реальная приёмка после обновления.
6. **Ограничения:** VPN всегда включён и неизменен, QR/TinyFish запрещены, персональные номера и коды/токены не включать в публичный репозиторий.
