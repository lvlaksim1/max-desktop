# MAX Desktop — открытые вопросы после исследования iframe, 27.10.2026
1. **Выявлено архитектурное отличие:** оригинальный Android JS bridge внедряется во все кадры, Windows MAX Desktop текущий сценарий ограничен top и единственным origin. Публичный SDK iframe может вообще не вызывать наш WebViewHandler. Но отсутствие обращения в v0.1.23 не доказывает участие iframe.
2. Не установлено, где именно закрытый мини-сервис проверяет Mobile ID: основной документ, iframe или сервер до события. Приватный вызов не находится в публичной JS библиотеке.
3. На исходном физическом Android код открывается без новой привязки, так как устройство уже ранее использовалось; текущий операторский запрос не доказан.
4. Серверная переносимость доверия Android→Windows и настоящая SMS-ветка конкретного кода не подтверждены.
5. Windows CI новых **исходников диагностики** 40435146121 PASS; но это не функциональная приёмка кодов и новый установщик не выпущен.
