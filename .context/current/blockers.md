# Незакрытые ограничения MAX Desktop

- Требуется пользовательская проверка v0.1.4 из проблемной сети. Результат скриншота v0.1.3 однозначно указывает на TLS_HANDSHAKE EOF, но не объясняет причину его возникновения на устройстве пользователя.
- Даже при успешном TLS в GitHub Windows нельзя утверждать, что сетевой путь пользователя работает: разные маршруты, промежуточные узлы и настройки Schannel.
- Встроенный тест на v0.1.4 не содержит телефон, токен или SMS-код и позволяет разделить проблему соединения и отправки кода.
- Реальная доставка кода/вход/восстановление сеанса не приняты; чаты, регистрация, подтверждение звонком и сообщения требуют отдельной разработки.
