# MAX Desktop — открытые ограничения после Android-приёмки

1. TCP/Android и WebAppPlatform=android подтверждены. Теперь защищённые коды ограничены привязкой доверенного устройства через Mobile ID или штатное СМС-подтверждение в MAX. Нельзя заменить операторское подтверждение программными признаками Android на компьютере.
2. Задержка загрузки miniapp 1–2 минуты наблюдалась владельцем, но не привязана к сетевому/серверному вызову; начальная навигация WebView2 успешна. Требуется отдельный безопасный замер при необходимости.
3. Изоляция нескольких сеансов WEB/TCP для одного номера ещё не реализована; текущую авторизацию не перезаписывать без резервной копии.
4. Не менять VPN, DNS, системный прокси и не добавлять отправку сообщений/QR/TinyFish.
