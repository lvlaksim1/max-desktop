# Ограничения и незакрытые проверки

- Нет результата подключения WEB/WebSocket из сети владельца MAX Desktop v0.1.7, несмотря на удачный анонимный INIT на GitHub Windows.
- Реальный запрос SMS и вход под учётной записью, CAPTCHA, 2FA и сохранение/восстановление веб-сеанса пока не подтверждены. Нельзя называть мессенджер полностью функциональным.
- Старый TCP/TLS в пользовательской сети обрывался до сертификата даже через системный прокси; альтернатива WebSocket может помочь, но не гарантирована.
- Отдельно не проверены на GUI пользователя X-to-tray, сворачивание на панель задач, меню выхода, повторный запуск и реальный цикл обновления.
- QR не использовать: явное решение пользователя. Секреты в GitHub, диагностике и сообщениях не публиковать.
