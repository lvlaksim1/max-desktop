# MAX Desktop — после трассировки Mobile ID

1. В v0.1.21 miniapp подтверждён как Android-платформа, но защищённые коды требуют операторской проверки доверенного устройства. `WebAppVerifyMobileId` выполняет HTTP через настоящий Android TRANSPORT_CELLULAR, которого в обычном Windows WebView2 нет.
2. Не установлен разрешённый MAX способ зарегистрировать доверенный ПК. Настраивать номер в клиенте или подделывать Mobile ID не является рабочим/допустимым решением.
3. 1–2 мин ожидания miniapp остаются без фактической сетевой/тайминговой трассы; причинность не доказана.
4. Не изменять системный VPN и сохранённые аккаунты, не включать QR/TinyFish/обычную отправку сообщений, не публиковать данные Mobile ID.
