# MAX Desktop — открытые препятствия после сотовой проверки Android (27.10.2026)
1. **Закрыто:** USB ADB обмен PASS и доступная сотовая сеть с INTERNET/VALIDATED подтверждены чтением Android ConnectivityService через PC Gateway; результат docs/protocol/android-cellular-connectivity-verified-2026-10-27.md.
2. **Неизвестно:** вызывал ли оригинальный MAX WebAppVerifyMobileId на ранее доверенном устройстве; последний просмотр кода не требовал новой привязки.
3. **Неизвестно:** серверное связывание операторского результата с устройством и сеансом; возможность разрешённого завершения настольной операции.
4. **Не принято:** MAX Desktop v0.1.23 не показывает настоящий код; WebView2 мост не увидел реального запроса.
5. **Не проверено:** серверный сценарий SMS для выбранного типа кода с 2FA на Windows.
- Не сбрасывать рабочую доверенную привязку, не извлекать защищённые значения/операторские доказательства и не изменять VPN без необходимости.
