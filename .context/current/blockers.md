# MAX Desktop — блокеры согласованного плана, 27.10.2026
1. В данном проектном исследовании ещё нет воспроизводимого успешного Mobile ID на настоящем Android с исследовательской SIM.
2. Неизвестна серверная привязка результата к устройству/сеансу и разрешено ли завершать процедуру в Windows.
3. MAX Desktop v0.1.23 не наблюдал реального запроса WebAppVerifyMobileId; собственная надпись о готовом мосте не является доказательством.
4. SMS-вариант при 2FA не подтверждён на тестовом Windows-клиенте и может зависеть от типа кода.
5. Фактическая конфигурация исследовательского Android/USB не проверена; не предполагать её без данных.
Реальный защищённый код в MAX Desktop не получен.
