# Текущие ограничения и проверочные этапы

- **Требуется пользовательская приёмка:** GitHub Actions проверяет сборку и компиляцию Inno Setup, но не проверяет интерактивный запуск и установку в реальном профиле Windows.
- **Протокол MAX:** `max-android-research` содержит статический анализ. Полная динамическая проверка авторизации, обновления сеанса и обмена сообщениями отсутствует. До её проведения сетевой транспорт сознательно отключён.
- **Обновление из приложения:** код опубликован и установщик собран; реальная последовательность 0.1.0 → будущий выпуск пока не проверена.
