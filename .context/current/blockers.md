# MAX Desktop — ограничения модификации APK

1. Исследовательский APK 26.35.1 технически пересобран и подписан, но ещё не установлен и не проверен на настоящем Android. Отдельная подпись может вызвать запрет обновления/проверку подлинности.
2. Экспортируются только обезличенные этапы Mobile ID с time_ms. Токены сеанса и доказательства оператора не экспортируются, перенос защищённого доверенного состояния в MAX Desktop не выполняется.
3. Доступ к кодам по-прежнему требует штатной привязки доверенного устройства. Не обещать, что диагностическая модификация её заменяет.
4. Не менять системный VPN и рабочие Windows-аккаунты.
