# MAX Desktop — блокирующие условия после полного APK-аудита

1. Подтверждён мобильный TCP(Android), WebAppPlatform=android, но коды защищены отдельной проверкой доверенного устройства/Mobile ID.
2. В 24 272 Java-файлах исходного MAX 26.35.1 нет обнаруженных стандартных Android API чтения номера SIM. Есть WebAppVerifyMobileId и получение сведений об операторе; простая подстановка телефона аккаунта не решает привязку.
3. Для просмотра кодов непосредственно в MAX Desktop нужен разрешённый MAX способ доверенной привязки ПК; он пока не установлен. Не обходить проверку, не вводить неподтверждённые SIM-данные.
4. Система VPN, защищённые WEB/TCP-сеансы и отправка сообщений остаются без изменений.
