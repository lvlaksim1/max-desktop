# MAX Desktop — ограничения после проверки v0.1.21

1. WEB-сеанс подтверждён и работает; WebAppPlatform=web. Мобильный TCP-транспорт есть в исходниках, но не используется активным аккаунтом.
2. Хранилище содержит один сеанс на номер; создание нового мобильного сеанса для того же номера может переписать WEB. Требуется независимое хранение и безразрушительная миграция до повторной авторизации.
3. Даже TCP(Android) не удостоверяет доверенное мобильное устройство. Сервис кодов подтверждения ограничен; обход доверия недопустим.
4. Не менять VPN, DNS, системный прокси, не включать обычную отправку сообщений; QR/TinyFish запрещены.
