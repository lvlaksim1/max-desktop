# Незакрытые проверки и ограничения

- Нужна пользовательская приёмка исправления выпадающих списков и обновления v0.1.0 → v0.1.1.
- Нужна реальная попытка входа своим номером; автоматические сборки не обращались к аккаунту MAX.
- Если сервер вернёт callOutParams вместо SMS-кода, программа выдаёт явное сообщение о неподдерживаемом способе; реализация подтверждения звонком не завершена.
- Если сервер начнёт использовать Zstandard-сжатие для ответов или изменит схему кадра, текущее подключение может завершиться диагностической ошибкой.
- Пока поддерживается один сохранённый сеанс. Чаты и обмен сообщениями не реализованы.
