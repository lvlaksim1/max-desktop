# MAX Desktop — условия SMS привязки и неопределённости

1. СМС для доверенного устройства официально документирована для Госуслуг при включённом пароле 2FA. Не доказана доступность на всех кодах, в независимом Windows клиенте и при отсутствии 2FA.
2. v0.1.22 добавляет исходный Mobile ID negative bridge no_cellular, но не вызывает серверный SMS напрямую и не подделывает операторское подтверждение. Реальная форма SMS и показ кода не проверены пользователем.
3. Встроенный браузер может иметь другой origin после редиректа, либо мини-приложение может потреблять приватное событие другим JS способом; в таком случае ответ не будет доставлен. Это нужно проверять на тестовой странице, не сохранять секретный URL.
4. Не изменять системный VPN, пароли аккаунтов или выданные токены.
