# MAX Desktop — открытые проверки после публикации v0.1.18

1. Реальная приёмка кнопки OPEN_APP в отмеченном владельцем сообщении Divan.ru: видимость кнопки, открытие окна и поведение самого мини-приложения.
2. Полноценный запуск подписанных мини-приложений MAX: неизвестен подтверждённый маршрут получения действительных WebAppData/initData из серверного сеанса; не подделывать подпись и не передавать login token третьим сторонам.
3. Старые страницы истории, группы, корректные имена отправителей, медиа и уведомления пока требуют отдельной проверки.
4. VPN не менять; QR/TinyFish не использовать; обычная отправка сообщений не требуется.
