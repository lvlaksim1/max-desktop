# MAX Desktop — блокирующие критерии 2026-10-27

1. Полноценная мобильная платформа в контексте мини-приложений не реализована. Фактическая авторизация может быть WEB, даже если TCP Android присутствует в коде. Окно WebView2 — отдельный браузер Windows.
2. v0.1.20 настоящую страницу @verificationcodes_bot загружает, но сервис ограничивает просмотр кодов мобильным приложением. Неизвестно, является ли основной причиной платформа в URL, окружение MAX Bridge или требование доверенного устройства. Одна смена User-Agent не позволяет сделать вывод.
3. v0.1.21 диагностическое отображение платформы/транспорта требует пользовательской проверки; оно не обходит ограничения защищённой функции.
4. Позже: пагинация, группы, имена отправителей, вложения, уведомления. VPN, учётные записи и отправка сообщений — не менять без указания.
