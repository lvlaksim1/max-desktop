# Передача состояния — MAX Desktop (26.10.2026)

Проект `lvlaksim1/max-desktop`, ветка main, Project Manager v2.

Текущий последний выпуск [v0.1.4](https://github.com/lvlaksim1/max-desktop/releases/tag/v0.1.4), Windows CI 40247220377 success и Release Actions 40247380634 success. Setup, Update и SHA-256 проверены в GitHub Releases.

Пользователь на v0.1.3 сообщил повторную ошибку `TLS_HANDSHAKE: EOF` при получении кода. В v0.1.3 дополнительный корневой сертификат MAX решил цепочку доверия на GitHub runner, но не исправил подключение в пользовательской сети. Проба 40246937237 показала успешный TLS 1.3 как с `SslProtocols.None`, так и с `Tls12 | Tls13`, поэтому нельзя объявлять различие TLS-версий корневой причиной.

В v0.1.4 модуль пробует до трёх DNS-адресов с паузой пять секунд и неизменной проверкой сертификата и SNI. Добавлена отдельная кнопка `Проверить соединение (без номера)`, отправляющая только анонимный `SESSION_INIT`. Диагностика пишет этап, число попыток и предъявление сертификата — без номера, токенов и кодов.

Следующее действие: пользовательский тест v0.1.4. Реальную авторизацию, SMS и чаты не считать подтверждёнными. Политика: только последний бинарный Release.
