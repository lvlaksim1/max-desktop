# Передача менеджера MAX Desktop — 26.10.2026, v0.1.11

Менеджер: тот же `project-manager`, репозиторий `lvlaksim1/max-desktop`, ветка `main`. Для восстановления прочитать `.context/ENTRYPOINT.md`, `.context/manifest.json`, `.context/manager/state-integrity.json`; не создавать нового менеджера.

**Обязательные условия владельца:** системный VPN всегда включён; никаких изменений его настроек. MAX может использовать отдельное физическое подключение, уже реализованное. QR и TinyFish запрещены. Никаких логов с телефоном, кодами и токенами.

**Реально принято:**
- На ПК владельца с включённым VPN в v0.1.9 подтверждены физическое защищённое WebSocket-соединение и SESSION_INIT. При START_AUTH сервер ответил «Проверка не пройдена».
- В v0.1.10 штатная VK Captcha открылась, пользователь поставил галочку (зелёная), но окно осталось висеть и отправка SMS не продолжилась. Пользователь прислал скриншот.
- Разбор обнаружил ручной iframe в `Resources/max-captcha.html` и самодельный разбор постсообщений. По SDK `@vkid/captcha` для проверки в чекбоксе существует публичное событие `CaptchaPublicEvents.SUCCESS`, возвращающее token. Документация: https://www.npmjs.com/package/@vkid/captcha

**Изменение и автоматическая проверка:**
- В v0.1.11 используется `CaptchaWidget` версии 2.0.0 и подписка на SUCCESS, мост отправляет WPF `solved` однократно. Старый разбор iframe сообщений удалён.
- Пакет собирается во время Windows Actions и локальный `captcha-sdk.js` встраивается в полный/обновляющий установщик, загрузка внешнего SDK пользователю не нужна.
- Node/JS имитация события SDK SUCCESS и проверки однократной передачи, Windows WPF, автономные тесты AUTH/SMS/неповторения кода прошли: https://github.com/lvlaksim1/max-desktop/actions/runs/40330935479 .
- Релиз v0.1.11 опубликован успешно: https://github.com/lvlaksim1/max-desktop/actions/runs/40331289185 , Setup/Update/SHA256; оставлен один выпуск.

**Открыто:** реальный SUCCESS и переход к выдаче SMS на ПК владельца пока не проверены; код, 2FA и LOGIN не подтверждены. Следующий шаг: обновить клиента до v0.1.11, нажать «Получить код» **один раз**, пройти VK Captcha и прислать обезличенный результат. Если капча опять зависнет — адресная диагностика нового SDK/визуального состояния, без изменения VPN или автоматического повторного SMS. После входа — чаты, история, уведомления и GUI-приёмка.
