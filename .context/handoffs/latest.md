# Передача менеджера MAX Desktop — 26.10.2026, v0.1.17

**Менеджер:** неизменный `project-manager`, `lvlaksim1/max-desktop`, `main`. Для восстановления нужен `.context/ENTRYPOINT.md` и успешные 8/8 SHA поколения в `.context/manager/state-integrity.json`.

**Реальная пользовательская проверка предыдущей версии:** в v0.1.16 реальные переписки загружаются, обычный чат показал историю из пяти сообщений. При открытии `Чат 0` весь клиент аварийно завершался. Причина в `MaxHistoryCodec.CreateRequest`: id=0 вызывает ArgumentOutOfRangeException, не перехваченный async void handler. В v0.1.17 добавлен CanOpenChat(0) и безопасное пояснение без запроса истории. Отправка сообщений по указанию владельца пока не нужна.

**Новая функция:** несколько аккаунтов. В `ProtectedMaxAccountVault` используется DPAPI-зашифрованный `max-accounts.dat`, одноразово переносится прежний одиночный DPAPI сеанс из `max-session.dat` без его удаления. Новые аккаунты создаются в отдельных слотах, выбранный номер сохраняется. Интерфейс показывает список, поддерживает добавление и переключение без повторного SMS, удаление с подтверждением без затрагивания других токенов. При смене изолируются чаты и история, прежний транспорт закрывается после успешного восстановления целевого.
