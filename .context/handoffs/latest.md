# Передача состояния — MAX Desktop, 26.10.2026

Репозиторий: `lvlaksim1/max-desktop`, main; Project Manager v2. Последний подтверждённый выпуск [v0.1.6](https://github.com/lvlaksim1/max-desktop/releases/tag/v0.1.6), Windows CI 40250385964 = success, Release Actions 40250537938 = success. Setup, Update и .sha256 опубликованы.

На пользовательском снимке v0.1.5: все шесть прямых TCP/TLS попыток через три проверенных домена MAX закрываются на `TLS_HANDSHAKE` (EOF) до получения сертификата. В GitHub Windows те же узлы успешно отвечают на анонимный SESSION_INIT; поэтому сбой зависит от реального маршрута/окружения, точная причина не подтверждена.

Исходный клиент игнорировал системный прокси: `TcpClient` всегда использовал прямое соединение. В v0.1.6 добавлен системный прокси из `HttpClient.DefaultProxy`, HTTP CONNECT/HTTPS CONNECT/SOCKS5 туннель с дополнительным независимым TLS к MAX и строгой проверкой имени/сертификата. При отсутствии прокси — прежний прямой маршрут. Прокси-пароли не передаются автоматически. Прошли локальные Windows-тесты туннелей и отказа 407.

Окно входа теперь позволяет прокручивать, выделять и копировать диагностическое сообщение. Следующий необходимый шаг — тест `Проверить соединение (без номера)` в v0.1.6 из пользовательской сети. Нельзя объявлять получение SMS/авторизацию подтверждёнными до реального успешного соединения.
