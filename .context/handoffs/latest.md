# Передача менеджера MAX Desktop — 26.10.2026, поколение 29

Постоянный менеджер project-manager в lvlaksim1/max-desktop, authority main. Начинать с .context/ENTRYPOINT.md и сверять 8/8 SHA state-integrity.json.

**Ранее принято:** v0.1.17 (несколько аккаунтов, чаты, история) и исправление физического сетевого маршрута miniapp в v0.1.19. Ранее кнопка «Посмотреть код» у @verificationcodes_bot открывала только публичную карточку бота.

**Протокол доказан:** WireCatLabs/max-cli ссылается на веб-клиент MAX: BOT_WEB_APP opcode 160, {botId, chatId, startParam?} → {url}. URL подписан и содержит временную авторизацию; нельзя публиковать/логировать/передавать во внешний браузер.

**v0.1.20 реализована и опубликована:** https://github.com/lvlaksim1/max-desktop/releases/tag/v0.1.20 ; Windows CI 40399496951, release 40399495892 success. Оба транспорта умеют запрос 160, Hybrid делегирует, UI вызывает серверный запрос и открывает ссылку из ответа WebView2. Отмена при смене аккаунта/чата, HTTPS-проверка, отсутствие журналирования signed URL. Setup/Update/SHA256 опубликованы; оставлен только последний релиз.

**Следующее:** реальная пользовательская проверка «Посмотреть код». Не считать аутентификацию или весь MAX Bridge принятыми до испытания. Если сервер требует доверенное устройство — соблюдать штатную проверку, не обходить ограничения. VPN не изменять; QR/TinyFish не использовать, отправку обычных сообщений не добавлять.
