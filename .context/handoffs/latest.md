# Передача менеджера MAX Desktop — 26.10.2026, v0.1.13

**Identity:** прежний `project-manager`, `lvlaksim1/max-desktop`, main, капсула и контрольные SHA в `.context/`. Не создавать новую сущность.

**Указания владельца:** системный VPN остаётся включённым, его настройки не менять. Трафик MAX может идти любым приложенческим маршрутом. QR и TinyFish не использовать. Никаких публичных токенов, паролей, SMS и персональных номеров.

**Существенное новое сведение от владельца:** при новой авторизации в официальном **Android-приложении** MAX капча и 2FA не спрашиваются. Наш WEB v11 клиент при коде SMS получил `WS_CHECK_CODE: Логин ограничен. Требуется установить 2FA`. Причина различия неизвестна (в частности, доверенность Android-устройства). Не считать 2FA глобально обязательной, но и не пытаться обойти политику сервера.

**Принятое решение:** использовать уже реализованный Android TCP бинарный протокол v10 на основе APK MAX 26.35.1. Ранее прямой транспорт не получал TLS через системный VPN. На ПК владельца через частный `pc-runner-gateway` Issue #404 проверен TLS с валидным сертификатом до всех трёх мобильных узлов на физическом IPv4 при включённом VPN.

**Изменение продукта:** v0.1.13 добавляет отдельный ручной `TCP Android через физический интерфейс (VPN включён)`, привязку исходящего сокета к физическому IPv4 без настройки системы/VPN, тот же строгий TLS/SNI, отдельную метку сеанса `TCP_PHYSICAL`. Автоматический режим остался WEB физическим; после возможного SMS переход между транспортами не происходит.

**Проверки:** GitHub Actions #40345635857 — настоящий анонимный SESSION_INIT(6) новым C# мобильным транспортом (успешный ответ + callsSeed); GitHub Windows CI #40345636022 — success; выпуск #40346233767 — success, Setup/Update/SHA256 v0.1.13, единственный опубликованный релиз.

**Граница доказанного:** TLS на ПК владельца, INIT C# на облачном Windows; реальный мобильный INIT/код/LOGIN/2FA в установленной v0.1.13 на ПК владельца ещё не проверены.

**Далее:** установить v0.1.13, выбрать новый Android физический TCP режим, нажать «Проверить соединение (без номера)». Если INIT успешен на ПК владельца — только тогда один запрос SMS и попытка реального LOGIN. Никаких обходов 2FA, раскрытия данных или изменения VPN. Затем чаты, сообщения, GUI.
