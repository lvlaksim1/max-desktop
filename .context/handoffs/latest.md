# Передача менеджера MAX Desktop — 26.10.2026, v0.1.10

Постоянный менеджер `project-manager`, репозиторий `lvlaksim1/max-desktop`, ветка `main`; для восстановления читать `.context/ENTRYPOINT.md`, `.context/capsule.json`, `.context/manifest.json`, `.context/manager/state-integrity.json`. Новую сущность не создавать.

**Неприкосновенные условия:** системный VPN всегда включён, не менять его параметры; MAX может выходить по любому маршруту на уровне приложения. QR-вход исключён. Не использовать TinyFish. Локальные задания выполнять через `lvlaksim1/pc-runner-gateway` с pinned SHA, не публиковать номер, SMS, пароли, CAPTCHA или сессионные токены.

**Сетевое достижение:** в v0.1.9 реализован PhysicalMaxWebSocketChannel через привязку исходящего сокета к физическому IPv4. PC Gateway Issues #399/#400/#402: прямой HTTPS к MAX даёт HTTP403, WebSocket Upgrade 101 и подходящий адаптер выбран. На присланном владельцем снимке установленной v0.1.9 на том же ПК при включённом VPN подтверждены TLS, WebSocket и SESSION_INIT. Прежний TLS_HANDSHAKE больше не блокирует выбранный режим.

**Текущая проблема:** после нажатия «Получить код» в v0.1.9 сервер ответил `WS_AUTH_REQUEST: Проверка не пройдена, попробуйте ещё раз`. По независимым исследованиям это характерно для VK ID anti-bot проверки, а протокол предусматривает `CAPTCHA_REQUEST` opcode 224, URL вида `id.vk.ru/not_robot_captcha` и `captchaToken` в `VERIFICATION_REQUEST` opcode 17. Точный код ошибки пользователя не установлен, гипотеза требует реальной приёмки. PC Gateway Issue #403: captcha-провайдер id.vk.ru доступен (302) при включённом VPN.

**Исправление:** в v0.1.10 добавлено состояние AwaitingCaptcha, запрос 224 после распознанного серверного отказа, отдельное WebView2 окно для самостоятельного прохождения человеком, при получении токена — один осознанный повтор START_AUTH; отмена без повтора SMS. Ввод кода/2FA/LOGIN и старые транспорты сохранены. Нет автоматического решения проверки. Сборка/автономные тесты GitHub Actions 40325552079 успешны; выпуск 40325831275 опубликован успешно; в Releases оставлен только v0.1.10 с полным и обновляющим установщиками и SHA-256.

**Следующее действие:** обновить v0.1.9 поверх до v0.1.10, нажать «Получить код» один раз, проверить появление VK Captcha и пройти её. Если успешно — проверить приём SMS, код, 2FA, LOGIN и восстановление сеанса. Если нет — по тексту обезличенной ошибки доработать интерфейс/протокол CAPTCHA без изменения VPN и новых необоснованных выпусков. Чаты и полная приёмка Windows-окна пока не завершены.
