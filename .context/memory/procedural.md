# Процедурная память MAX Desktop

- При WPF/Windows Forms глобальные стили TextBlock могут ухудшать контраст текста в системных ComboBox. Использовать наследуемый динамический Foreground окна и явно читаемое оформление ComboBox/ComboBoxItem; проверять оба состояния списков.
- Для отладки нативного MAX различать удачную компиляцию, совпадение формата пакетов и **сервером подтверждённую** авторизацию. Только последний результат подтверждает вход.
- Эталон APK 26.35.1 (6867) и хеши метаданных держать согласованными; не смешивать параметры отпечатка разных версий.
- При диагностике авторизации получать от пользователя этап, текст ошибки и время, не собирать пароли, коды и токены в публичном репозитории.
- Публикация: Windows CI → GitHub Release vX.Y.Z → проверка наличия Setup/Update/SHA-256 → когерентная актуализация менеджера.
- Coupled-state файлы менеджера редактировать единым Git commit вместе с новой generation и git-blob-sha1 контрольными суммами.
