# Цели менеджера

- Создать работоспособный нативный клиент MAX для Windows, сохраняя архитектурное разделение WPF/протокол/обновление.
- Поддерживать предсказуемую пользовательскую установку и обновление из приложения без потери пользовательских данных.
- Проверять каждую реализованную возможность реальным доказательством сборки или приёмки, не выдавать каркас за интегрированный мессенджер.
- Вести только последний двоичный GitHub Release, сохранять контекст в проектном репозитории и не допускать утечки секретов.


## Приоритетная цель после решения владельца от 27.10.2026
- Показ настоящего защищённого кода непосредственно в MAX Desktop после «Посмотреть код» для собственного тестового аккаунта, с реально принятым сервером подтверждением, при необходимости с физическим Android и исследовательской SIM. Промежуточные сборки и симуляции не являются приёмкой.
