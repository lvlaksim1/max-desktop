# Активные обязательства — MAX Desktop

## I-001 — нативный каркас и установка
- Статус: реализовано; актуальная версия v0.1.5, CI и выпуск Windows успешны.

## I-002 — пользовательская приёмка TCP/TLS
- Статус: **active**. В v0.1.4 все три попытки к IP-адресам `api2.oneme.ru` закончились EOF до сертификата. В v0.1.5 включён переход к `api.oneme.ru` и `api-tg.oneme.ru`; эти адреса в GitHub Windows подтвердили TLS и SESSION_INIT. Из пользовательской сети теста v0.1.5 ещё нет.
- Пользователь должен нажать `Добавить аккаунт → Проверить соединение (без номера)`, передать только обезличенное сообщение.

## I-003 — реальная авторизация MAX
- Статус: **active**. Возможность получения кода, проверки кода, подтверждения звонком, 2FA, вход по токену и последующие чаты требуют испытания живого аккаунта; нельзя утверждать успех по анонимному SESSION_INIT.
