## I-002 — авторизация обычного аккаунта MAX по SMS, без QR
- Статус: **active**.
- В v0.1.7 у пользователя TCP/TLS EOF и .NET WebSocket WS_CONNECT/WebSocketException; до SMS-пакетов выполнение не дошло.
- В v0.1.8 внедрён третий транспорт Chromium/WebView2; независимый анонимный INIT из GitHub Windows прошёл (40255463057). Старые способы сохранены, сообщения .NET WebSocket дополнены безопасными кодами ошибок.
- Ждём тест `WebSocket через браузер Edge → Проверить соединение (без номера)` в сети владельца. Реальный SMS-запрос и успешный вход **не доказаны**; QR не использовать.
