# MAX Desktop — активные обязательства после v0.1.9

I-001 **active**: установка v0.1.9, сохранение данных, обновление, пользовательская приёмка окна/трея и второго запуска.
I-002 **active**: авторизация по телефону/SMS без QR. Новый физический маршрут реализован; локальные TLS и WebSocket 101 подтверждены, анонимный SESSION_INIT C# подтверждён на внешнем Windows Runner. Следующее — проверить SESSION_INIT именно установленной v0.1.9 на пользовательском ПК при включённом VPN, затем выполнить один запрос SMS, код, 2FA при необходимости, LOGIN и восстановление сеанса. Реальная авторизация не подтверждена.
I-003 **active**: чаты, сообщения, вложения и уведомления после входа; заглушки не выдавать за готовое.
I-004 **active**: итоговая GUI-приёмка X→трей, «−»→панель задач, выход из трея, один экземпляр, завершение при обновлении.
I-005 **active до пользовательской проверки**: клиент MAX работает через физический интерфейс при включённом VPN без изменения его параметров. Маршрут по HTTPS/WebSocket подтверждён на локальном ПК, приложение v0.1.9 реализовано; точная причина отказа пути Xray не установлена, но для рабочего альтернативного маршрута не обязательна.
