# Подтверждённые сведения менеджера MAX Desktop — 26.10.2026

- [Repo] Публичный `lvlaksim1/max-desktop`, основная ветка `main`, .NET 8/WPF, Project Manager v2; интерфейс и установочные выпуски по принципам MailRu Desktop.
- [Пользователь, версия v0.1.5] Все шесть прямых TLS-попыток к `api2.oneme.ru`, `api.oneme.ru`, `api-tg.oneme.ru` закончились EOF до получения сертификата. [Пользователь, v0.1.6] Три попытки через системный прокси и шесть напрямую дали тот же TLS_HANDSHAKE/EOF. Это **не** отказ по номеру или SMS.
- [GitHub Windows 40248116311] Анонимный TCP SESSION_INIT успешно ответил на трёх названных узлах из среды GitHub Windows; среда пользователя отличается.
- [Владелец 26.10.2026] QR-авторизация не подходит, **не включать** QR в MAX Desktop. Использовать другие способы входа, включая WebSocket и SMS.
- [Независимые исходники] `huxuxuya/python-max-client`, `MaxApiTeam/PyMax`, `Tellarion/webmaxsocket` демонстрируют обработку `INIT(6)`, `AUTH_REQUEST(17)`, `AUTH(18)`, `LOGIN(19)`, дополнительной проверки (115) и WEB/WebSocket. Это технический ориентир; успешный реальный вход пользователя MAX Desktop не подтверждён.
- [Код v0.1.7] Новый `MaxWebSocketCodec` (JSON, protocol v11) и `NativeMaxWebSocketTransport` используют `wss://ws-api.oneme.ru/websocket`, Origin `https://web.max.ru`, системный прокси и TLS с проверкой сертификата. `HybridMaxTransport` поддерживает автоматический выбор WEB→TCP, отдельный WebSocket и TCP. Автоматическое резервирование допускается только до отправки SMS-запроса во избежание двойных кодов.
- [GitHub Windows probe 40253115470] Анонимная проверка WebSocket + INIT прошла успешно, без телефона, SMS, QR и токена. [GitHub CI 40253731349] Windows-сборка, тесты протоколов и обновителя успешно завершены.
- [Код v0.1.7] Зашифрованное DPAPI-хранилище остаётся; сохранённые TCP-сеансы распознаются по умолчанию (поле Transport необязательное). WEB-сеансы сохраняются с `Transport=WEB`.
- [Владелец 26.10.2026, код v0.1.7] Крестик основного окна прячет в трей; системное «Свернуть» остаётся в панели задач; меню значка трея содержит «Выход»; повторный запуск активирует единственный работающий экземпляр через Mutex/EventWaitHandle. Обновитель использует явное завершение, не скрытие в трей.
- [GitHub Actions 40253731311, Release] Успешно опубликован **последний выпуск v0.1.7** — Setup/Update/SHA-256. В GitHub Releases оставлен только v0.1.7.
- **Ограничения:** реальный SMS-код, WebSocket-подключение из сети пользователя, пароль 2FA, вход по токену, переписка и фактическое поведение трея на компьютере пользователя требуют приёмки. Внешняя CI не заменяет её.
