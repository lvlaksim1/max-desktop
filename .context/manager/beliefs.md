# Подтверждённые сведения менеджера MAX Desktop — 26.10.2026

- Публичный репозиторий `lvlaksim1/max-desktop`, Project Manager v2, .NET 8/WPF, пользовательская установка и обновления по образцу MailRu Desktop.
- Пользовательская диагностика v0.1.5: **все шесть прямых подключений** к трём доменам `api2.oneme.ru`, `api.oneme.ru`, `api-tg.oneme.ru` завершились EOF на `TLS_HANDSHAKE` **до получения сертификата**. Телефон, SMS-код и протокольные команды авторизации не участвовали. Это не подтверждает отказ в авторизации и не доказывает конкретную причину сетевого обрыва.
- Независимая Windows GitHub Actions [40248116311](https://github.com/lvlaksim1/max-desktop/actions/runs/40248116311) ранее подтвердила TLS 1.3 и успешный анонимный `SESSION_INIT` на всех трёх узлах, но из другой сети.
- В исследовании кода установлено: `TcpClient` из v0.1.5 всегда подключался напрямую и не учитывал системный прокси. В .NET 8 `HttpClient.DefaultProxy` учитывает системные настройки Windows и переменные среды; это обоснованная диагностическая гипотеза, **не подтверждённая первопричина** пользовательского сбоя.
- В v0.1.6 внедрён проверяемый системный HTTP/HTTPS CONNECT или SOCKS5-туннель перед прямым TCP. Поверх него всегда выполняется независимый TLS MAX с обязательной проверкой имени и цепочки сертификата; пароли прокси не передаются автоматически. При отсутствии/недоступности прокси остаётся прямой маршрут к проверенным узлам.
- Обезличенная диагностика сообщает наличие прокси и результаты, но не раскрывает его адрес, IP-адреса, номер, SMS, пароль или токен. Сообщение стало прокручиваемым, выделяемым и копируемым из окна входа.
- Windows CI [40250385964](https://github.com/lvlaksim1/max-desktop/actions/runs/40250385964) success, включая локальные тесты HTTP CONNECT, SOCKS5 и отказа 407; выпуск установщиков [40250537938](https://github.com/lvlaksim1/max-desktop/actions/runs/40250537938) success.
- Последний выпуск [v0.1.6](https://github.com/lvlaksim1/max-desktop/releases/tag/v0.1.6) содержит Setup, Update и SHA-256. Реальное подключение из сети пользователя и доставка кода **пока не подтверждены**.
