# MAX Desktop — дальнейший план, 26.10.2026

1. Системный VPN всегда включён. Его настройки, прокси, DNS и маршруты не изменять. Владелец разрешил приложению MAX выбирать любой работающий маршрут, включая вне VPN.
2. v0.1.9 уже опубликована: https://github.com/lvlaksim1/max-desktop/releases/tag/v0.1.9 . Windows-сборка и выпуск успешны. Отдельный сетевой модуль использует IPv4 физического интерфейса, TLS-валидацию и WebSocket; автоматический выбор сначала Physical, затем Edge/.NET/TCP только до возможной отправки SMS.
3. Владелец устанавливает обновление поверх v0.1.8 и выбирает «Добавить аккаунт» → «Автоматически» → «Проверить соединение (без номера)». Нужно подтвердить SESSION_INIT на этом ПК. При сбое изучить копируемую диагностику, не изменяя VPN.
4. При подтверждённом INIT — один запрос SMS, код, 2FA при необходимости, LOGIN и проверка восстановления защищённого сеанса.
5. Затем развивать чаты, сообщения и вложения, проверить уведомления, окно/трей/один экземпляр/обновитель.
6. Локальные задачи только через приватный pc-runner-gateway и разрешённые project PowerShell задания с точным SHA. TinyFish не использовать.
