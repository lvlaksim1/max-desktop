# План MAX Desktop — после выпуска v0.1.5

1. Получить результат диагностики `Проверить соединение (без номера)` на Windows v0.1.5 в текущей сети пользователя. Новый отчёт включает статусы трёх серверов MAX, без номера, IP-адресов и токенов.
2. При успешном TCP/TLS/SESSION_INIT протестировать однократный запрос кода пользователем; затем диагностировать ответ AUTH_REQUEST и необходимые ветви звонка/2FA.
3. Если все три серверных имени показывают EOF до сертификата, проверить локальную маршрутизацию и влияние VPN/прокси, сетевого фильтра и альтернативного интернет-канала. Не менять слепо параметры SMS-протокола и не отключать валидацию TLS.
4. При положительной авторизации последовательно внедрить чаты, историю, отправку, вложения и уведомления.
5. Поддерживать один последний двоичный GitHub Release, успешную Windows-сборку, безопасное хранение данных и актуальную капсулу Project Manager.
