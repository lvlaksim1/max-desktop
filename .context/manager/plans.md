# Текущий план менеджера

1. Получить обратную связь о первом запуске `MaxDesktop_Setup_v0.1.0.exe`: корректность установки, отображение окон, настройки, сворачивание в область уведомлений и удаление приложения.
2. При выявленных дефектах внести узкие исправления, повторить Windows CI и выпустить следующую версию через `release.yml`.
3. Сопоставить статический разбор `max-android-research` с разрешённой записью собственного тестового входа, подтвердить сетевые пакеты, кодирование, ключи сеанса и переподключение.
4. Реализовать WPF-независимый транспорт MAX только на подтверждённых параметрах, затем подключить управление аккаунтами, чаты и сообщения.
5. На каждом этапе сохранять проверенные решения и работать с последним двоичным выпуском в GitHub Releases.
