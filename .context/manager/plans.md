# План MAX Desktop

1. Провести реальную приёмку выпуска v0.1.1: обновление из v0.1.0, тёмные выпадающие списки, ввод номера телефона, получение кода, проверка кода, возможный пароль.
2. При неудаче входа получить от владельца безопасную диагностику: этап, дословный текст ошибки, примерное время; без номера, SMS-кода, токена и пароля.
3. Проверить на живом аккаунте SESSION_INIT, AUTH_REQUEST, AUTH, LOGIN, восстановление защищённого токена после перезапуска. Зафиксировать различие между подтверждённым сервером успехом и результатом сборки.
4. По фактическому ответу сервера реализовать неподдерживаемый вид подтверждения звонком, если он потребуется; не выдавать SMS за универсальный метод.
5. После успешного входа добавить список чатов и историю сообщений с отдельной проверкой нативного протокола.
6. Публиковать новые выпуски только после успешной Windows CI; сохранять один двоичный Release; обновлять капсулу атомарно с контрольными суммами.
