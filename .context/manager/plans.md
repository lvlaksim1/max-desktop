# План MAX Desktop

1. Получить подтверждение установки `MaxDesktop_Update_v0.1.2.exe` вручную поверх v0.1.1 (без удаления приложения) и сохранения состояния/настроек.
2. Подтвердить, что окно приложения показывает v0.1.2, пользовательские настройки и тёмные списки сохранены и исправно отображаются.
3. При следующем выпуске проверить уже исправленную кнопку «Обновить» по сценарию v0.1.2 → следующая версия. Нельзя считать её принятой только по тестам работы с локальным файлом.
4. При повторении `ProtocolException` выяснить источник, операцию, время и безопасную диагностику; не смешивать с доказанной ошибкой файлового дескриптора.
5. По разрешённой тестовой авторизации MAX подтвердить реальные `SESSION_INIT`, `AUTH_REQUEST`, `AUTH`, `LOGIN`; затем включать получение чатов/сообщений.
6. Не добавлять двоичные файлы в Git; публиковать только последний GitHub Release. Состояние менеджера фиксировать атомарно с контрольными суммами.
