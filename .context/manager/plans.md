# MAX Desktop — план после v0.1.11 (26.10.2026)

1. **Не менять VPN:** он постоянно включён. MAX может использовать свой физический маршрут, уже подтвердивший SESSION_INIT на ПК.
2. **Проведённое исправление:** в v0.1.10 после зелёной галочки VK Captcha окно не закрывалось. Прямая iframe-интеграция не использовала событие SDK SUCCESS. В v0.1.11 встроен @vkid/captcha 2.0.0 с обработкой SUCCESS и передачей token в WPF, проверен автономный JS тест на однократную обработку.
3. **Установить v0.1.11** поверх текущего клиента: https://github.com/lvlaksim1/max-desktop/releases/tag/v0.1.11 . CI 40330935479, release 40331289185 успешны. Выпуск предыдущей версии удалён.
4. **Испытание на реальном ПК:** «Добавить аккаунт» → автоматический (физический первым) → «Получить код» **один раз** → при появлении VK Captcha вручную отметить «Я не робот». Ожидается закрытие окна и переход к SMS; если не сработает, получить только обезличенный текст или скриншот без токенов и личных значений.
5. **Проверить** принятый START_AUTH, SMS/код, запрос дополнительного пароля если потребуется, LOGIN, защищённое сохранение и восстановление сеанса. QR запрещён, автоматических повторов SMS нет.
6. После подтверждённого входа — чаты, история и отправка сообщений, вложения/уведомления; затем приёмка GUI и обновителя.
7. Инфраструктура: через GitHub connector работать с исходниками, Actions Windows Runner для сборок; через частный pc-runner-gateway — только разрешённые локальные испытания с pinned SHA. Не отключать или перенастраивать системный VPN.
