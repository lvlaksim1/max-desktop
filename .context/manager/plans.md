# План MAX Desktop после выпуска v0.1.7

1. Установить `MaxDesktop_Update_v0.1.7.exe` поверх v0.1.6 (либо использовать встроенную кнопку обновления); данные сохраняются.
2. В окне входа выбрать **«WebSocket (веб-протокол)»**, затем `Проверить соединение (без номера)` из пользовательской сети. Проверить TLS и анонимный `INIT(6)` без учётных данных.
3. Если WebSocket доступен, пользователь однократно запрашивает SMS на своём номере, вводит код и при необходимости 2FA. Анализировать обезличенные серверные ответы, возможные CAPTCHA/ограничения. QR не предлагать.
4. Если WEB не подключается, сравнить доступность через альтернативную сеть и режим TCP; не делать повторных отправок SMS при неопределённости ответа сервера.
5. Пользователь проверяет четыре сценария GUI: X → трей; «−» → панель задач; контекстное меню трея → «Выход»; повторный запуск → одно уже работающее окно. Дополнительно проверить обновление поверх работающего приложения (явный выход).
6. После доказанного успешного входа реализовывать чаты, историю, сообщения, вложения, уведомления и восстановление сессии на реальной учётной записи.
7. Сохранять один последний двоичный GitHub Release, проходящие Windows CI и защищённую капсулу Project Manager.
