# План MAX Desktop после выпуска v0.1.8

1. Пользователь обновляется до v0.1.8, открывает окно входа и выбирает **«WebSocket через браузер Edge»**, затем **«Проверить соединение (без номера)»**. Проверка анонимная и не вызывает SMS.
2. При успехе Chromium/INIT сделать **один** запрос кода; исследовать ответ AUTH_REQUEST и дальнейший вход, 2FA/капчу (если сервер потребует), не публикуя номер, токен или код.
3. При сбое браузерного подключения использовать показанное безопасное сообщение, различить отсутствие WebView2 Runtime, сбой Chromium WebSocket, блокировку TLS или маршрута Windows. При необходимости сравнить сеть провайдера с мобильной точкой доступа. Не отключать проверку сертификатов и не повторять прежние эксперименты без новых доказательств.
4. Если Chromium доступен, а .NET нет, признать это свойством сетевого стека/маршрута, но не считать успешной авторизацией до подтверждённого LOGIN и пользовательского испытания.
5. Пользователь проверяет X→трей, кнопку «−»→панель задач, меню трея «Выход», повторный запуск→один экземпляр; в случае ошибки исправлять отдельный сценарий.
6. После подтверждённой авторизации внедрять реальные чаты, историю, отправку, вложения и уведомления.
7. Поддерживать один последний двоичный GitHub Release, CI/интеграционные доказательства и целостность капсулы менеджера. QR исключён.
