# План MAX Desktop

1. Пользователь обновляет программу до v0.1.4, открывает `Добавить аккаунт → Проверить соединение (без номера)`. Получить результат `TCP_CONNECT`, `TLS_HANDSHAKE`, `SESSION_INIT` либо `SESSION_INIT_OK` и диагностический текст без персональных данных.
2. При успехе анонимной проверки попробовать запрос кода и определить реальную реакцию сервера на `AUTH_REQUEST` без публикации телефонного номера/токенов.
3. При повторении TLS EOF на v0.1.4 проанализировать доступность **из пользовательской сети**, в том числе маршрутизацию, промежуточный узел, влияние конфигурации сетевого подключения и сертификатов Windows. Не утверждать причину из результатов внешнего GitHub runner.
4. По подтверждённому живому серверному обмену уточнить авторизацию: коды, звонок, 2FA, хранение/восстановление сеанса. Затем реализовать чаты и сообщения.
5. Сохранять только последний бинарный GitHub Release и проверять каждый релиз успешным Windows CI. Изменения связанных файлов Project Manager публиковать атомарно вместе с контрольными хэшами.
