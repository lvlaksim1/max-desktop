# Ограничения MAX Desktop

- Публичный GitHub-проект; не хранить в истории Git учётные данные, токены, личную переписку, двоичные выпуски и сетевые захваты с секретами.
- Подчиняться политике Repo Factory: не отслеживать `.exe`, `.dll`, `.msi`, архивы; каждый отслеживаемый файл не более 5 МиБ.
- Хранить только последний двоичный GitHub Release, не загружать артефакты сборки через GitHub Actions.
- Сборка Windows .NET 8 / WPF. Установка без прав администратора; текущие пользовательские данные сохранять во время обновления.
- Сетевой протокол MAX исследуется по наблюдаемому обмену и проверенным участкам собственного статического анализа APK; недоказанные параметры не выдавать за рабочие.
- Система локального хранения паролей/ключей при реализации должна защищать данные пользователя средствами Windows.
- Общие принципы установки, темы и поведения окон перенять из MailRu Desktop, не копировать его почтовую логику и API.
- Каждое утверждение о собранном установщике подтверждать успешным запуском сборки и существованием файлов выпуска; факт запуска интерфейса на компьютере пользователя является отдельной приёмкой.
