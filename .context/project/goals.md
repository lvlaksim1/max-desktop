# Цели MAX Desktop

1. Нативный клиент MAX под Windows 10/11 без встроенного браузера, на C# / .NET 8 / WPF.
2. Поддерживать несколько аккаунтов, переписки, вложения, поиск и уведомления по мере подтверждения сетевого протокола.
3. Повторить удобный пользовательский принцип MailRu Desktop: отдельная установка для текущего пользователя, обновление из программы, сохранение настроек, разделителей, размеров окон и темы.
4. Сохранять только подтверждённую функциональность. Не представлять локальный макет интерфейса или статический анализ APK как рабочую серверную авторизацию.
5. Выпускать проверенные установщики `MaxDesktop_Setup_vX.Y.Z.exe` и `MaxDesktop_Update_vX.Y.Z.exe` только через GitHub Releases.
