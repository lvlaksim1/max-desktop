# PC Runner Gateway client

This repository is connected to `lvlaksim1/pc-runner-gateway`.

For every task involving execution on the trusted Windows PC, start with:

`.pc-gateway/ENTRYPOINT.md`

The standard Client Kit uses the gateway's private GitHub Issue queue and does not require GitHub-hosted Actions in this repository.

Do not create a repository-level self-hosted runner for this integration and do not bypass the gateway contract.
