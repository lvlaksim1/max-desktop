# MAX Desktop — реализация каркаса 0.1.1

Основа: .NET 8, WPF, отдельные проекты приложения, протокола и агента обновления.

## Что реализовано
- Нативное главное окно с разделителями и списками аккаунтов, чатов и сообщений.
- Пользовательские настройки оформления, положения и размеров окон.
- Светлая/тёмная/системная темы и восемь основных цветов; исправлена контрастность текста выпадающих списков тёмной темы.
- Одно запущенное приложение на пользовательскую сессию, восстановление окна при повторном запуске.
- Сворачивание в область уведомлений, отдельное окно настроек.
- Обновление: GitHub Releases, сравнение версий, загрузка по HTTPS, проверка опубликованной SHA-256, запуск отдельного установщика.
- Установщики Inno Setup для первой установки и обновления, установка без прав администратора.

## Ограничения
- Нативный вход по номеру и проверочному коду, дополнительный пароль и восстановление защищённого токена реализованы программно. **Реальный успешный вход не подтверждён**, требуется пользовательская проверка версии 0.1.1. Загрузка чатов, сообщения, звонок-подтверждение и регистрация нового пользователя не реализованы.
- Проверки Windows-сборки и установщиков выполняются в GitHub Actions; результат необходимо проверять по конкретному запуску.
- Проверка SHA-256 удостоверяет соответствие опубликованной контрольной сумме, но не заменяет проверку подлинности издателя.
- Изменение оформления и другие локальные функции не означают успешной интеграции с MAX.
