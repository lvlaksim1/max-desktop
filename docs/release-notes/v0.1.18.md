# MAX Desktop v0.1.18 — предварительная поддержка мини-приложений

- Сообщения MAX теперь распознают кнопки `OPEN_APP` в `attaches[].keyboard.buttons` для TCP/MessagePack и WEB/WebSocket.
- Кнопки выводятся непосредственно под соответствующими сообщениями ботов.
- Нажатие открывает адрес мини-приложения в отдельном окне WebView2. HTTPS-проверка адреса, изолированный режим браузера, отсутствие доступа к токенам MAX и автоматическим системным разрешениям.
- Добавлены протокольные регрессионные тесты для обоих форматов и проверки небезопасных URL.
- Сохранены ранее подтверждённые несколько аккаунтов, восстановление сеанса, чаты и история.

**Ограничение:** подлинные подписанные платформой данные `WebAppData`/`initData` и мост MAX в этой версии не воспроизведены. Мини-приложения, требующие платформенную авторизацию, могут не функционировать. Реальная приёмка запуска Divan.ru пока не завершена. Обычная отправка сообщений остаётся отключённой; системный VPN не изменяется.
