# MAX Desktop v0.1.19 — исправление сетевого подключения мини-приложений

- Устранено несоответствие сетевых маршрутов основного MAX Desktop и окна мини-приложения: встроенный WebView2 теперь подключается к доменам MAX через локальный прокси, использующий физический IPv4-интерфейс компьютера.
- Только `max.ru`, его поддомены и домены `oneme.ru` используют физическое подключение; другие сайты продолжают использовать установленный системный прокси или штатную маршрутизацию Windows.
- Системный VPN остаётся включённым, его параметры, DNS и общая маршрутизация не изменяются.
- HTTPS не перехватывается и не расшифровывается. Прокси доступен только на `127.0.0.1`, ограничен CONNECT/443, запрещает локальные/частные адреса и завершается при закрытии окна.
- Отдельный временный профиль WebView2 защищает сохранённые авторизации MAX; добавлены проверки небезопасных адресов и локального CONNECT.
- Сохраняются кнопки `OPEN_APP`, несколько аккаунтов, чаты и история из v0.1.18.

**Граница проверки:** исправление основано на подтверждённой ранее работе физического сетевого маршрута MAX, но настоящая загрузка страницы `max.ru` в мини-приложении проверяется владельцем после обновления. Встроенный мост MAX и подписанные `WebAppData/initData` пока не реализованы; открытие страницы не доказывает работоспособность всего мини-приложения. Отправка обычных сообщений остаётся отключённой.
